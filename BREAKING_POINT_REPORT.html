🌐 Why a Single Machine Cannot Open More than ~55k TCP Sockets

Every TCP connection is defined by a unique 4-tuple: {Source IP, Source Port, Dest IP, Dest Port}. When running a benchmark from a single client machine to a single server IP on port 443:

  • The Dest IP and Dest Port (443) are fixed.
  • The client machine has only one Source IP.
  • Therefore, the Source Port is the only variable. In the TCP header, ports are 16-bit integers ($2^{16} = 65,536$). After OS-reserved ports, exactly ~55,000 to 60,000 ephemeral ports exist.
  • Industry Solution to test 100k+ Users: Use Docker Multi-Container Workers (tests/load/benchmark-50k.js). Each container has its own virtual IP address and its own 65,535 port range, allowing infinite horizontal load generation!
